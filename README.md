# Studi_Kasus_3_Julian
dalam kodingan ini, saya membuat tentang peminjaman buku perpustakaan. Dimana nanti ada list buku yang dapat kita pinjam. Nah, kita bisa meminjam hanya jika ada buku di list itu. Jika kita meminjam tapi tidak memilih buku nanti akan muncul peringatan "anda belum meminjam buku". Dan jika sudah meminjam buku, maka kita dapat menghapus buku yang sudah kita pinjam, dan nanti hasilnya akan di tampilkan. Tambahan, jika kita meminjam buku tapi tidak ada di list buku itu, maka akan muncul peringatakan.
